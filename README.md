# 📄 Resume Screening System using Machine Learning

## 📌 Project Overview
This project is an AI/ML-based Resume Screening System that analyzes resumes and matches them with job requirements. It helps automate the recruitment process by ranking candidates based on skills, experience, and relevance.

---

## 🧠 Problem Statement
Manual resume screening is time-consuming and may lead to bias or human error. This system uses Machine Learning techniques to automatically evaluate and rank resumes based on job requirements.

---

## 🚀 Features
- Upload and process resumes
- Extract key skills and experience
- Compare resume with job description
- Generate eligibility score / ranking
- Fast and automated screening process

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP (Natural Language Processing)
- Flask / Streamlit (if used)
- TF-IDF Vectorization
